# Sprite assets

The game draws painted PNG sprites from `assets/sprites/`. `assets/sprites/manifest.js` (generated by `tools/build_manifest.py`)
tells the game what exists. Nothing else needs registering.

## Layout
One folder per unit: `assets/sprites/<unit>/<view>_<frame>.png` plus an optional `meta.json`.

| view | the unit is facing |
|---|---|
| `n`, `ne`, `nw` | away from the camera / away-right / away-left (the squad) |
| `s`, `se`, `sw` | toward the camera / toward-right / toward-left (machines) |
| `e`, `w` | screen right / left (legacy single-image art) |

A missing view falls back to its mirror, then the nearest neighbour. A unit with 6 frames per view animates through them.
`meta.json`: `{ "h": 56, "muz": {"n": [x, height]}, "lights": {...}, "vents": {...} }`
 (`h` world height; `muz` where shots leave the weapon (x px from centre, height px); `lights` spotlight origins; `vents` where fire starts.)

## Adding art
1. Generate a sheet (prompts: `docs/prompt_builder.html`), flat fuchsia background.
2. `tools/import_strip.py sheet.png <unit> --groups s:6,se:6 --rows 2 --bg fuchsia --tol 150 --dilate 0 --height 230 --h 150 --fringe 22`
   (soldiers: `--groups s:1,n:6,ne:6,nw:6 --height 110`; touching cells: `--split-wide`; several rows: `--rows N`).
3. `tools/defringe.py` removes any pink haze left on the edges (safe to re-run).
3b. `tools/optimize_sprites.py` shrinks the PNGs about 4x with no visible change (run it after importing).
4. `tools/gen_vents.py <unit>` once for big sprites (where boss/vehicle fire starts), then `tools/build_manifest.py assets/sprites`.
5. Check it in `docs/sprite_demo.html`.

Sizing: machines about 230 px tall, soldiers about 110 px. Bosses are drawn up to ~270 canvas px tall, so ask the generator for
500-800 px tall figures for them. `tools/render3d/run.py model.glb <unit> --install` turns a 3D model into 8-direction sprites.

Old and superseded art lives outside the project in `../CyberNetAttack_archive/`.
